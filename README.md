# LEARNOVA

LEARNOVA is a standalone learning and student collaboration platform prototype.

## Current preview
- Premium responsive student dashboard
- Class creation dialog concept (private invite-only by default)
- Student navigation for classes, library, assignments, calendar, AI Study Coach, Study Rooms and Flashcards
- PWA manifest and custom brand icon

## Important
This first deployment is a visual frontend prototype. Authentication, database persistence, class invitation links, roles and realtime collaboration are not enabled yet. They will be connected to a dedicated Supabase project after organization selection and security setup.

## Deploy
Static site served directly by Vercel from the repository root.
